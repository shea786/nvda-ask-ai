Ask GPT NVDA add-on (version 1.1.0)

Ask ChatGPT a question from anywhere in Windows, by typing or by voice, and hear the answer read by NVDA. The add-on uses the official OpenAI Codex command line program, signed in with your ChatGPT account. Usage counts toward your ChatGPT plan (Plus, Pro, Team or Business). No API key is needed and there is no pay-per-use billing.

New in 1.1.0: NVDA stays quiet while you dictate, conversations are saved and can be continued later, each conversation can have a project folder where GPT can create files, answers can be saved as Word, PDF and other files, and you can choose the model for each conversation.

One-time setup

  1. Install Node.js (the LTS version) from nodejs.org and accept the defaults in the installer. Or open a command prompt and type winget install OpenJS.NodeJS.LTS, then press Enter.
  2. Open a new command prompt: press Windows+R, type cmd and press Enter. It must be a new one, opened after Node.js was installed.
  3. Type npm install -g @openai/codex and press Enter. Wait until the prompt returns. This can take a minute.
  4. Check that it worked: type codex --version and press Enter. You should hear a version number such as "codex-cli 0.160.0". If you hear "not recognized" instead, close the command prompt, open a new one and try again. Then type exit and press Enter. Alternatively, download the Windows codex program from github.com/openai/codex/releases and set its path in the add-on settings.
  5. Install this add-on (open the askGPT-1.1.0.nvda-addon file), and restart NVDA when asked.
  6. Open the NVDA menu (NVDA+N), then choose Preferences, then Settings, and select the Ask GPT category.
  7. Press Sign in with ChatGPT. NVDA says "Your browser will open. Sign in with your ChatGPT account, then come back to NVDA. NVDA will tell you when you are signed in." Your web browser then opens the ChatGPT sign-in page. Sign in as usual. The page may ask for a verification code sent by e-mail or text message, a two-factor authentication code, or a "verify you are human" check (CAPTCHA). If a CAPTCHA is hard to solve with NVDA, try its audio option, or ask a sighted helper for this one step.
  8. When the browser says you are signed in, go back to NVDA: press Alt+Tab repeatedly until you hear "NVDA Settings". NVDA announces "Signed in with ChatGPT" by itself. You can also press Check status. If you do not finish within about 3 minutes, NVDA says "Sign-in was not completed. Press Sign in to try again."
  9. Press OK to close the settings.

If the browser did not open: press Copy sign-in link (Alt+Y) in the Ask GPT settings right after pressing Sign in, then open your browser, press Alt+D or Control+L to move to the address bar, paste with Control+V and press Enter. You can also open a command prompt and type codex login.

Asking a question

  1. Press NVDA+Alt+G from anywhere, or choose NVDA menu, Tools, Ask GPT. The Ask GPT dialog opens with the cursor in the Question box. It continues your most recent conversation, even after restarting NVDA. The window title says which conversation it is.
  2. Type your question and press Enter to send it. To start a new line inside the question instead, press Shift+Enter.
  3. NVDA says "Asking GPT" and plays a soft beep every two seconds while waiting (you can turn the beep off in the settings). Answers usually take 5 to 30 seconds.
  4. When the answer arrives, NVDA reads it. It is also added to the Conversation box.
  5. Type a follow-up question and press Enter. GPT remembers the earlier questions of this conversation.

While waiting, press Escape (or the Cancel button, Alt+C) to cancel the question. When nothing is pending, Escape closes the dialog. If you close the dialog with the Close button while GPT is still working, the question keeps running, and NVDA speaks the answer when it is ready. The answer is always stored in the conversation where you asked the question, even if you switch to another conversation meanwhile.

The Ask GPT dialog

Press Tab to move through the controls in this order:

  • Question (Alt+Q), then Ask (Alt+A; while waiting it becomes Cancel, Alt+C) and Dictate (Alt+D).
  • Conversation (Alt+V): the questions and answers so far.
  • Copy last answer (Alt+O) and Save answer as (Alt+S).
  • Model (Alt+M) and Reasoning effort (Alt+E) for this conversation.
  • Project folder (Alt+J, shows "None" when there is none), Choose project folder (Alt+F), Open folder in Explorer (Alt+X) and Clear project folder (Alt+L).
  • Conversations (Alt+R), New conversation (Alt+N) and Close.

Stopping and replaying answers

  • Press Control to stop NVDA reading an answer.
  • Press NVDA+Alt+Shift+G from anywhere to hear the last answer of the current conversation again, even after closing the dialog or restarting NVDA.
  • Press NVDA+Alt+Shift+G twice quickly to open the last answer in a window you can read with the arrow keys, line by line or word by word, exactly as GPT wrote it, including any code. Press Escape to close that window.

Asking by voice

Press Alt+D (Dictate). NVDA says "Voice typing. Speak your question, then press Enter to send." After the message, Windows voice typing opens and NVDA goes quiet, so it does not read every word as it is typed into the Question box. Speak your question. NVDA speaks again, exactly in the speech mode you had before (talk, beeps or on-demand), as soon as one of these happens:

  • you press Enter to send the question (NVDA then says "Asking GPT");
  • you press Escape, or press Alt+D again (this also stops voice typing);
  • you move out of the Question box or switch to another window;
  • no new words arrive for a few seconds (the "Dictation silence timeout" setting, 4 seconds by default), or nothing at all is typed for 20 seconds.

NVDA then says "Dictation finished" followed by what you dictated, so you can check it before pressing Enter. If nothing was typed, it says "Dictation finished, nothing was typed". Braille is not affected. Voice typing is built into Windows 10 and 11 (the same as pressing Windows+H). It needs an internet connection, and "Online speech recognition" turned on in Windows Settings, Privacy, Speech. Headphones help so the microphone does not hear NVDA. If you switch to another window before voice typing opens, it is not started, and NVDA tells you.

Reviewing and saving answers

  • Press Alt+V to move to the Conversation box, then use the arrow keys to read the conversation line by line. The cursor is placed at the start of the newest answer, also when you open the dialog again. It is never moved while you are reading the box.
  • Copy last answer (Alt+O) copies the latest answer to the clipboard exactly as GPT wrote it.
  • Save answer as (Alt+S) saves the latest answer as a file. Choose the format with the arrow keys and press Enter: Word document (.docx), PDF document (.pdf), plain text (.txt), web page (.html) or Markdown (.md). Then type a file name (it starts with your question) and press Enter. The file goes into the conversation's project folder, or into Documents\Ask GPT when there is no project folder. An existing file is never replaced: a number such as "(2)" is added instead. NVDA says the file name and the folder. The add-on makes these files itself, so Word does not need to be installed. PDF files use a standard font that covers Western European languages; other characters, for example Chinese, Arabic or emoji, appear as "?". Use Word or plain text for those languages.

Project folders: letting GPT create files

Each conversation can have a project folder, for example a folder with your notes or documents. Press Choose project folder (Alt+F) and pick the folder; NVDA says its name. With a project folder, GPT works inside that folder: it can read the files there, and (if the setting "Allow GPT to create and edit files in the project folder" is on, which is the default) create new files there, for example "Write my cover letter as a Word document". GPT tells you the file name, and NVDA also says "Created: cover letter.docx" (or "Changed: ...") after the answer. These lines are also added to the Conversation box. Open folder in Explorer (Alt+X) opens the folder; Clear project folder (Alt+L) removes it from the conversation (no files are deleted).

What protects your files. Codex is told not to change or delete existing files unless you ask, and it runs in Codex's own "workspace-write" sandbox: it may write only inside the project folder, it has no internet access while working on files, and the .git, .codex and .agents folders stay read-only. The add-on never uses Codex's "bypass sandbox" mode. On Windows this sandbox is Codex's Windows sandbox. How strong it is depends on your Windows version and Codex version: on Windows 11 24H2 or later Codex can use a built-in Windows isolation feature, while older systems use a weaker fallback that may need a one-time administrator setup by Codex. The Codex documentation does not say what happens when no Windows sandbox is set up, so only choose project folders you are happy for GPT to change, and keep a backup of important files. If you prefer GPT to only read your files, turn off "Allow GPT to create and edit files in the project folder" in the settings. Without a project folder, Codex always runs read-only in an empty private folder.

Models

The Model choice (Alt+M) lists the models Codex offers to your account, taken from Codex's own list (the file models_cache.json in the .codex folder of your user profile, which Codex updates when it runs). "Default" lets Codex pick your plan's default model. When you change the model NVDA says, for example, "Model changed to GPT 6.1 Sol". Reasoning effort (Alt+E) lists only the levels the chosen model supports; lower is faster. The model and effort are remembered with each conversation. New conversations start with the defaults from the settings.

Conversations

Every conversation is saved automatically after each answer and when you change its name, model or project folder. New conversation (Alt+N) starts a fresh one; the previous one stays saved. Press Conversations (Alt+R) in the Ask GPT dialog, choose NVDA menu, Tools, Ask GPT conversations, or assign a key to "Show Ask GPT conversations" in Input gestures. The conversation manager opens with the list of conversations, newest first, with the current one selected. The list has the columns Title, Updated, Messages and Project.

  • Continue (Alt+C or Enter): open the selected conversation in the Ask GPT dialog, with its model and project folder.
  • Rename (Alt+R): give it a title. An empty title goes back to the automatic one (the first question).
  • Archive (Alt+A): hide it from the list without deleting it. Show archived (Alt+H) lists archived conversations; for those the button is Unarchive.
  • Delete (Alt+D or the Delete key): permanently delete it, after a Yes/No question.
  • Export (Alt+X): save the whole conversation as a Word, PDF, text, web page or Markdown file (into its project folder, or Documents\Ask GPT).
  • Import (Alt+I): add a conversation from a .json file, for example one copied from another PC.

Where conversations are stored. One file per conversation in %LOCALAPPDATA%\askGPT\conversations. In the settings you can choose another Conversations folder, for example a OneDrive folder, to continue your conversations on another PC. The files contain your questions and answers in plain text (JSON), so keep them somewhere private.

Settings

NVDA menu, Preferences, Settings, Ask GPT:

  • Status: shows Signed in with ChatGPT, Not signed in, Codex CLI not found, or Node.js not found.
  • Sign in with ChatGPT (Alt+S), Check status (Alt+H), Sign out (Alt+U, asks for confirmation), Copy sign-in link (Alt+Y, available while signing in).
  • Codex executable path (Alt+X): leave blank to find Codex automatically. Use Browse (Alt+B) to choose codex.exe or codex.cmd if it is installed somewhere unusual. For an npm install the path is %APPDATA%\npm\codex.cmd; you can type it exactly like that.
  • Default model (Alt+M): the model new conversations start with. The list comes from Codex; you can also type a model name. Blank uses your plan's default.
  • Default reasoning effort (Alt+R): Low is fastest and fine for most questions.
  • Instructions for GPT (Alt+I): tells GPT how to answer. The default asks for short plain-text answers suited to a screen reader.
  • Speak answers automatically (Alt+P, on by default).
  • Keep conversation context for follow-up questions (Alt+K, on by default). About the last 10 questions and answers are sent along with each new question.
  • Beep while waiting for an answer (Alt+W, on by default).
  • Allow GPT to create and edit files in the project folder (Alt+J, on by default). When off, GPT can only read the project folder.
  • Answer timeout in seconds (Alt+T, default 180, from 30 to 600).
  • Dictation silence timeout in seconds (Alt+D, default 4, from 2 to 15): how long NVDA waits after the last dictated words before speaking again.
  • Conversations folder (Alt+F, blank for the default) and Choose folder (Alt+E).

Troubleshooting

  • "The OpenAI Codex program was not found": install it as described above, then restart NVDA. If it still is not found, set the Codex executable path to %APPDATA%\npm\codex.cmd.
  • "Node.js was not found": Codex was installed with npm, but Node.js is missing. Install Node.js (see step 1), then restart NVDA.
  • "Codex is not signed in": the add-on offers to open its settings; press Sign in with ChatGPT.
  • "Signed in with an API key": Codex is using an API key, which is billed per use. Press Sign out, then Sign in with ChatGPT.
  • "You have reached the usage limit of your ChatGPT plan": Codex usage limits depend on your plan. Try again later.
  • "Couldn't reach ChatGPT": check your internet connection and try again.
  • "The project folder no longer exists": the folder was moved or deleted. Choose another folder or clear it.
  • The model list only shows Default: Codex has not saved its model list yet. Ask one question, then reopen the dialog.
  • No answer in time: try again, choose a lower reasoning effort, or increase the timeout.
  • Error entries in the Conversation box end with "Technical details", which you can copy into a support request.

Privacy

Your questions, and the earlier part of the conversation when context is on, are sent to OpenAI by the Codex program under your ChatGPT account. Without a project folder, Codex runs in a read-only sandbox in an empty folder (%LOCALAPPDATA%\askGPT\workdir) and is told not to run commands or touch files. With a project folder, Codex can read the files in it (see "Project folders" above). The add-on saves your conversations as described under "Where conversations are stored". Codex may keep its own session logs in the .codex folder in your user profile. When NVDA exits, any running Codex program is stopped and speech is turned back on if you were dictating. The add-on does nothing on secure screens such as the Windows sign-in screen.
