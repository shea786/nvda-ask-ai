Ask AI NVDA add-on (version 1.2.0)

Ask ChatGPT or Claude a question from anywhere in Windows, by typing or by voice, and hear the answer read by NVDA. The add-on uses the official command line program of each service, signed in with your own subscription:

  • ChatGPT through OpenAI's Codex program, signed in with your ChatGPT plan (Plus, Pro, Team or Business).
  • Claude through Anthropic's Claude Code program, signed in with your Claude plan (Pro, Max, Team or Enterprise).

Usage counts toward your plan. No API key is needed and there is no pay-per-use billing. You need only one of the two services, but you can use both and choose per conversation.

New in 1.2.0: the add-on was called Ask GPT and is now Ask AI. Claude is available as a second service. Your Ask GPT settings and conversations are copied over automatically, and Ask AI offers once to remove the old Ask GPT add-on (both would answer NVDA+Alt+G); restart NVDA afterwards. The add-on can also check for updates itself. Also new: find text in a conversation (Ctrl+F) and search all conversations, recall earlier questions with Up and Down, drafts (Ctrl+S), a status report (NVDA+Alt+Shift+S), "Ask about this" (NVDA+Alt+A) for the text you are reading, and attached files and screenshots.

Ask AI is free software under the GNU General Public License version 2 (see copying.txt in the add-on folder).

One-time setup for ChatGPT (Codex)

  1. Install Node.js (the LTS version) from nodejs.org and accept the defaults in the installer. Or open a command prompt and type winget install OpenJS.NodeJS.LTS, then press Enter.
  2. Open a new command prompt: press Windows+R, type cmd and press Enter. It must be a new one, opened after Node.js was installed.
  3. Type npm install -g @openai/codex and press Enter. Wait until the prompt returns. This can take a minute.
  4. Check that it worked: type codex --version and press Enter. You should hear a version number such as "codex-cli 0.160.0". If you hear "not recognized" instead, close the command prompt, open a new one and try again. Then type exit and press Enter. Alternatively, download the Windows codex program from github.com/openai/codex/releases and set its path in the add-on settings.

One-time setup for Claude (Claude Code)

  1. Open PowerShell: press Windows+R, type powershell and press Enter.
  2. Type irm https://claude.ai/install.ps1 | iex and press Enter. The installer shows no progress while it downloads; wait until the prompt returns. If you prefer, install it in a command prompt with npm install -g @anthropic-ai/claude-code (needs Node.js 22 or later) or winget install Anthropic.ClaudeCode.
  3. Open a new command prompt and type claude --version. You should hear a version number such as "2.1.314 (Claude Code)". Ask AI needs Claude Code 2.1.259 or later; claude update updates it.

The add-on finds Claude Code in %USERPROFILE%\.local\bin\claude.exe (the installer above), %APPDATA%\npm\claude.cmd (npm) or on the PATH. Git for Windows is not needed, because the add-on never lets Claude run commands.

Install and sign in

  1. Install this add-on (open the askAI-1.2.0.nvda-addon file), and restart NVDA when asked.
  2. Open the NVDA menu (NVDA+N), then choose Preferences, then Settings, and select the Ask AI category.
  3. In Show settings for service (Alt+G), choose ChatGPT (Codex) or Claude (Claude Code). The controls in the group below it, "ChatGPT account and defaults" or "Claude account and defaults", then belong to that service. About half a second after you stop on a service, NVDA says its status once, for example "Claude: Signed in with Claude".
  4. Press Sign in to ChatGPT or Sign in to Claude (Alt+S). NVDA says "Your browser will open. Sign in with your ChatGPT account (or Claude account), then come back to NVDA. NVDA will tell you when you are signed in." Your web browser then opens the sign-in page. Sign in as usual. The page may ask for a verification code sent by e-mail or text message, a two-factor authentication code, or a "verify you are human" check (CAPTCHA). If a CAPTCHA is hard to solve with NVDA, try its audio option, or ask a sighted helper for this one step.
  5. When the browser says you are signed in, go back to NVDA: press Alt+Tab repeatedly until you hear "NVDA Settings". NVDA announces "Signed in with ChatGPT" or "Signed in with Claude" by itself. You can also press Check status. If you do not finish within about 5 minutes, NVDA says "Sign-in was not completed. Press Sign in to try again."
  6. To use both services, choose the other one in Show settings for service and sign in again. Default AI service (Alt+V) decides which service new conversations use.
  7. Press OK to close the settings.

If the browser did not open: press Copy sign-in link (Alt+Y) in the Ask AI settings right after pressing Sign in, then open your browser, press Alt+D or Control+L to move to the address bar, paste with Control+V and press Enter. For ChatGPT that is all. For Claude, the page shows a code at the end. Claude Code waits for it, so after you copy the link Ask AI opens a box for the code by itself: copy the code from the page, go back to NVDA Settings, paste it into the box and press Enter. You can also press Enter sign-in code (right after Copy sign-in link) at any time while signing in. You can also open a command prompt and type codex login or claude auth login.

If the Status says Signed in with an API key, which is billed per use, the program is signed in to a pay-per-use API account instead of your subscription: press Sign out, then sign in again. Ask AI never passes API keys from environment variables (OPENAI_API_KEY, CODEX_API_KEY, ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN) to the programs, so they cannot switch you to API billing.

Asking a question

  1. Press NVDA+Alt+G from anywhere, or choose NVDA menu, Tools, Ask AI. The Ask AI dialog opens with the cursor in the Question box. It continues your most recent conversation, even after restarting NVDA. The window title says the conversation and the service, for example "Ask AI – Trip to Paris – Claude".
  2. Type your question and press Enter to send it. To start a new line inside the question instead, press Shift+Enter.
  3. NVDA says "Asking ChatGPT" or "Asking Claude" and plays a soft beep every two seconds while waiting (you can turn the beep off in the settings). Answers usually take 5 to 30 seconds.
  4. When the answer arrives, NVDA reads it. It is also added to the Conversation box, after "ChatGPT:" or "Claude:".
  5. Type a follow-up question and press Enter. The AI remembers the earlier questions of this conversation.

While waiting, the Ask button becomes Cancel: press Alt+C to cancel the question. That is the only way to cancel. Escape (or Close) closes the dialog and the question keeps running; NVDA says "Still working; the answer will be spoken when ready." The answer is always stored in the conversation where you asked the question, even if you switch to another conversation meanwhile.

The Ask AI dialog

Press Tab to move through the controls in this order:

  1. Question (Alt+Q)
  2. Ask (Alt+A); while waiting it is Cancel (Alt+C)
  3. Dictate (Alt+D)
  4. Only when something is attached to the next question: the list Attached to next question (Alt+T), Remove item (Alt+I), and, when screen text is attached, Include a screenshot of the window's title (everything visible in it) (Alt+U, off by default). See "What is attached, and when it is cleared".
  5. Conversation (Alt+V): the questions and answers so far
  6. Copy last answer (Alt+O)
  7. Save answer as (Alt+W)
  8. Attach files (Alt+H)
  9. Conversation options (Alt+P)
  10. Conversations (Alt+R)
  11. New conversation (Alt+N)
  12. Close

Conversation options opens a small dialog with the conversation's AI service (Alt+S), Model (Alt+M), Reasoning effort (Alt+E), Project folder (Alt+J) with Choose project folder (Alt+F), Open folder in Explorer (Alt+X) and Clear project folder (Alt+L), and OK and Cancel. Nothing changes until you press OK; NVDA then says one summary, for example "Claude, Opus, medium effort, no project folder." The model and effort are remembered for each service in the conversation, so switching back to a service brings its choices back. From the Ask AI dialog, Alt+S, Alt+M, Alt+E and Alt+J still work: they open Conversation options on that field.

Finding text in a conversation

Press Ctrl+F anywhere in the Ask AI dialog, type what to find and press Enter. The search ignores upper and lower case. The cursor moves to the match in the Conversation box, which gets the focus with the match selected, and NVDA says, for example, "Match 2 of 5" followed by the line. F3 goes to the next match and Shift+F3 to the previous one; after the last match NVDA says "Wrapped to first match". With no match NVDA says "No matches for" and your text. Ctrl+F offers your last search again.

To search all conversations, open the conversation manager (Alt+R) and type in its Search field (Alt+S). The list keeps only conversations whose title or text contains your words, about a third of a second after you stop typing, and NVDA says, for example, "3 match; first: Trip to Paris". Press Enter to continue the first match at once. Tick Show archived to search archived conversations too.

Earlier questions and drafts

  • In an empty Question box, press Up to bring back your earlier questions, newest first: first those of this conversation, then your other recent questions. Down goes forward again. NVDA reads each one. Past the ends NVDA says "No earlier question" or "No later question" and gives back what you had typed. In a recalled question of several lines, Up and Down first move through its lines: Up recalls the next one only from the first line, Down only from the last line. As soon as you edit a recalled question, Up and Down move inside the text again. Ask AI keeps your last 100 questions in %LOCALAPPDATA%\askAI\history.json, not in the NVDA settings.
  • Ctrl+S saves the Question text as the conversation's draft ("Draft saved"). The draft is also saved silently when you close the dialog or switch conversations, and comes back when you open or continue the conversation: "Continuing Trip to Paris. Draft restored." Sending the question clears it.

Status report and announcements

Press NVDA+Alt+Shift+S from anywhere to hear what Ask AI is doing. It never starts a program; the sign-in state is the one Ask AI last saw. It says one of:

  • "ChatGPT, working for 40 seconds. Conversation: Trip to Paris." ("just started" in the first second)
  • "Dictating."
  • "Waiting for sign-in."
  • "Not signed in to Claude." when the current conversation's service was last seen signed out
  • "Idle. Last answer from ChatGPT at 15:05 in Trip to Paris." (the time in your Windows time format)
  • "Idle." when there is no answer yet

followed, when something waits for the next question, by for example "Context from Word and 2 files attached to the next question."

When an answer arrives while you work in another app (the Ask AI dialog is not in front), NVDA says "Ask AI answer," the conversation title and a colon before the answer, for example "Ask AI answer, Trip to Paris: ...". A failure is "Failed:", the title and the reason. Turn this off with "Announce when answers finish while working in other apps" (Alt+U) in the settings.

Ask about this

Select text in any program, or move the navigator to something, and press NVDA+Alt+A. Ask AI takes the selected text, or else the name, value and text of the navigator object (up to 20,000 characters), together with the program and window names. The Ask AI dialog opens on your current conversation and NVDA says what was attached, for example "Attached: Selected text from Word, 1,240 characters. Type your question." or "Attached: Text of the current object (document) from Edge, cut to 20,000 characters. Type your question." The same line is the first item of Attached to next question; press Enter on it to read the captured text in a window, with the arrow keys, before you send it. Delete (or Remove item) takes it off again.

The text is sent with your next question only, in a block marked as text from your screen that the AI must treat as data, not as instructions. The conversation keeps only the summary, not the text.

Include a screenshot of ... (everything visible in it) (Alt+U), named after the window, sends a picture of that window too. The picture is taken when you send the question, not before, and only if the box is ticked; the window draws itself (PrintWindow), so the Ask AI dialog in front of it is not in the picture. If the window was closed meanwhile, Ask AI says so and does not send. Pictures are made at most 4,096 pixels wide or high. If the picture is nearly all one colour, Ask AI asks "Screenshot looks blank, possibly because Screen Curtain is on. Send it anyway?" so you can cancel and turn Screen Curtain off first. ChatGPT receives the picture as an image; Claude opens it with its file reading tool. It is saved only in a private folder for that question, deleted afterwards.

Ask about this refuses password and other protected fields ("Can't use protected or password fields"), and does nothing on secure screens.

Attaching files

Press Attach files (Alt+H) and choose one or more files (hold Control to select several). NVDA says, for example, "2 files attached", and they appear in Attached to next question (Alt+T), as "notes.txt, text, 1 KB". Delete or Remove item (Alt+I) removes the selected one.

  • Pictures (png, jpg, jpeg, gif, webp, up to 10 MB each) are sent as images, like the screenshot.
  • Text files (UTF-8, up to 200 KB each and 500 KB together) are put into the question.
  • Other files, and bigger ones up to 25 MB, can only be read by Claude: they are copied into a private folder that Claude may read for that question, deleted afterwards. For ChatGPT, Ask AI refuses to send them: "ChatGPT can only receive text files and images; Claude can read other files." Files over 25 MB are refused.
  • A question longer than 32,000 characters (for example a long paste) is sent as an attached file, question.txt; NVDA says "Long text attached as a file".

The conversation keeps the names of attached files, not their content.

What is attached, and when it is cleared

  • Screen text from Ask about this and the screenshot choice are for the next question only. They are cleared when you send, when you close the Ask AI dialog, start a New conversation or switch to another conversation, so they never ride along silently.
  • Attached files also go with the next question only and are cleared when it is sent. If you close the dialog first they stay, and NVDA says "Still attached: 2 files" whenever the dialog opens or comes back to the front.
  • The status report (NVDA+Alt+Shift+S) always says what is attached.

Stopping and replaying answers

  • Press Control to stop NVDA reading an answer.
  • Press NVDA+Alt+Shift+G from anywhere to hear the last answer of the current conversation again, even after closing the dialog or restarting NVDA.
  • Press NVDA+Alt+Shift+G twice quickly to open the last answer in a window you can read with the arrow keys, line by line or word by word, exactly as the AI wrote it, including any code. Press Escape to close that window.

Asking by voice

Press Alt+D (Dictate). NVDA says "Voice typing. Speak your question, then press Enter to send." After the message, Windows voice typing opens and NVDA goes quiet, so it does not read every word as it is typed into the Question box. Speak your question. NVDA speaks again, exactly in the speech mode you had before (talk, beeps or on-demand), as soon as one of these happens:

  • you press Enter to send the question (NVDA then says "Asking ChatGPT" or "Asking Claude");
  • you press Escape, or press Alt+D again (this also stops voice typing);
  • you move out of the Question box or switch to another window;
  • no new words arrive for a few seconds (the "Dictation silence timeout" setting, 4 seconds by default), or nothing at all is typed for 20 seconds.

NVDA then says "Dictation finished" followed by what you dictated, so you can check it before pressing Enter. If nothing was typed, it says "Dictation finished, nothing was typed". Braille is not affected. Voice typing is built into Windows 10 and 11 (the same as pressing Windows+H). It needs an internet connection, and "Online speech recognition" turned on in Windows Settings, Privacy, Speech. Headphones help so the microphone does not hear NVDA. If you switch to another window before voice typing opens, it is not started, and NVDA tells you.

Reviewing and saving answers

  • Press Alt+V to move to the Conversation box, then use the arrow keys to read the conversation line by line. The cursor is placed at the start of the newest answer, also when you open the dialog again. It is never moved while you are reading the box.
  • Copy last answer (Alt+O) copies the latest answer to the clipboard exactly as the AI wrote it.
  • Save answer as (Alt+W) saves the latest answer as a file. Choose the format with the arrow keys and press Enter: Word document (.docx), PDF document (.pdf), plain text (.txt), web page (.html) or Markdown (.md). Then type a file name (it starts with your question) and press Enter. The file goes into the conversation's project folder, or into Documents\Ask AI when there is no project folder. An existing file is never replaced: a number such as "(2)" is added instead. NVDA says the file name and the folder. The add-on makes these files itself, so Word does not need to be installed. PDF files use a standard font that covers Western European languages; other characters, for example Chinese, Arabic or emoji, appear as "?". Use Word or plain text for those languages.

Project folders: letting the AI read and create files

Each conversation can have a project folder, for example a folder with your notes or documents. Open Conversation options (Alt+P, or Alt+J straight to the folder), press Choose project folder (Alt+F) and pick the folder.

Which folders are allowed. A project folder must be a folder of your own on a fixed local drive. Ask AI refuses, with the reason, network paths (\\server\share and device paths), removable, network and CD drives, whole drives such as C:\, your user folder itself, anything inside AppData (where programs keep their settings, including Ask AI's own data), the Startup folders, and the Windows, Program Files and ProgramData folders. The check looks only at the path before anything opens it, so a network path is never contacted. Conversation files can be imported or synced, so a project folder from a file is checked again whenever the conversation is opened or used, and removed (with a message) if it is not allowed.

Permission to write. The first time a conversation uses a folder while "Allow the AI to create and edit files in the project folder" is on, Ask AI asks once: "Allow the AI to create and change files in" the folder? Yes is remembered for that folder in the NVDA settings (not in the conversation file); No makes that question read-only and you are asked again next time. After an answer, NVDA says which files were created or changed ("Created: cover letter.docx"); it compares files up to three folder levels deep, including hidden ones, and says "Many files changed or the folder is too large to list the changes" for very large folders. Open folder in Explorer (Alt+X) opens the folder; Clear project folder (Alt+L) removes it from the conversation (no files are deleted). Only choose project folders you are happy for the AI to change, and keep a backup of important files.

With ChatGPT (Codex), Codex's shell (its only way to open or change files) is switched on only when writing is allowed. It then runs in Codex's "workspace-write" sandbox: it may write only inside the project folder, it has no internet access while working on files, and the .git, .codex and .agents folders stay read-only. Codex can then make Word or PDF files, for example "Write my cover letter as a Word document". On Windows this sandbox is Codex's Windows sandbox; how strong it is depends on your Windows and Codex versions, and the Codex documentation does not say what happens when no Windows sandbox is set up. Without permission to write, and without a project folder, Codex gets no shell at all, so it cannot open files in the project folder: paste or attach the text, or use Claude.

With Claude (Claude Code), there is no operating-system sandbox on Windows. Instead the add-on only gives Claude the file tools Read, Glob and Grep (to read and search) and, when writing is allowed, Write and Edit. Claude Code keeps these tools inside the project folder. Claude gets no tool to run commands or programs and no web access, and the folder's own Claude Code settings are ignored. Because Claude cannot run programs, it can only create text-based files, such as Markdown (.md), web pages (.html) or CSV; for a Word or PDF document, ask for the text and use Save answer as, or ask Claude to write Markdown or HTML. Without a project folder, Claude has no tools at all, except reading the private folder of the files you attached.

Models

The Model choice in Conversation options (Alt+M from the Ask AI dialog) lists the models of the conversation's service. For ChatGPT, the list is the models Codex offers to your account, taken from Codex's own list (the file models_cache.json in the .codex folder of your user profile, which Codex updates when it runs). For Claude, the list is Claude Code's model names Sonnet, Opus, Haiku and Fable (Fable only if your plan includes it). "Default" lets the service pick your plan's default model. Reasoning effort (Alt+E) lists the levels the chosen model supports; lower is faster. The service, model and effort are remembered with each conversation, and the model and effort for each service, so switching services back and forth keeps them. New conversations start with the defaults from the settings. You can type any other model name in the settings' Default model box.

Conversations

Every conversation is saved automatically after each answer and when you change its name, service, model or project folder. New conversation (Alt+N) starts a fresh one with the default AI service; the previous one stays saved. Press Conversations (Alt+R) in the Ask AI dialog, choose NVDA menu, Tools, Ask AI conversations, or assign a key to "Show Ask AI conversations" in Input gestures. The conversation manager opens with the list of conversations, newest first, with the current one selected. The list has the columns Title, Updated, Messages, Project and Service. The Search field (Alt+S) above the list filters it (see "Finding text in a conversation"); Enter in it continues the first match. The Project column shows the full path of each conversation's project folder.

  • Continue (Alt+C or Enter): open the selected conversation in the Ask AI dialog, with its service, model and project folder.
  • Rename (Alt+R): give it a title. An empty title goes back to the automatic one (the first question).
  • Archive (Alt+A): hide it from the list without deleting it. Show archived (Alt+H) lists archived conversations; for those the button is Unarchive.
  • Delete (Alt+D or the Delete key): permanently delete it, after a Yes/No question.
  • Export (Alt+X): save the whole conversation as a Word, PDF, text, web page or Markdown file (into its project folder, or Documents\Ask AI). Answers are headed ChatGPT or Claude.
  • Import (Alt+I): add a conversation from a .json file, for example one copied from another PC. An imported conversation is not trusted: its project folder is dropped (choose one again), dates in the future are set to now, and its messages are sent to the AI marked as untrusted earlier conversation, to be treated as data, not as instructions.

Where conversations are stored. One file per conversation in %LOCALAPPDATA%\askAI\conversations. In the settings you can choose another Conversations folder, for example a OneDrive folder, to continue your conversations on another PC. The files contain your questions and answers in plain text (JSON), so keep them somewhere private. On first start Ask AI copies the conversations of Ask GPT from %LOCALAPPDATA%\askGPT\conversations; the old files are left in place.

Settings

NVDA menu, Preferences, Settings, Ask AI:

  • Default AI service (Alt+V): the service new conversations use.
  • Show settings for service (Alt+G): which service the group "Service account and defaults" below shows (status, sign-in buttons, program path, default model and effort). NVDA says the shown service's status once, about half a second after you stop on it.
  • Status: shows Signed in with ChatGPT, Signed in with Claude, Not signed in, Codex not found, Claude Code not found, or Node.js not found.
  • Sign in to ChatGPT or Sign in to Claude (Alt+S), Check status (Alt+H), Sign out (Alt+T, asks for confirmation), Copy sign-in link (Alt+Y, available while signing in) and, for Claude, Enter sign-in code.
  • Codex executable path or Claude Code executable path (Alt+X): leave blank to find the program automatically. Use Browse (Alt+B) to choose codex.exe, codex.cmd, claude.exe or claude.cmd if it is installed somewhere unusual. For an npm install of Codex the path is %APPDATA%\npm\codex.cmd; you can type it exactly like that.
  • Default model (Alt+M): the model new conversations of this service start with. You can also type a model name. Blank uses your plan's default.
  • Default reasoning effort (Alt+R): Low is fastest and fine for most questions.
  • Instructions for the AI (Alt+I): tells the AI how to answer. The default asks for short plain-text answers suited to a screen reader. They are sent with every question, to both services.
  • Speak answers automatically (Alt+P, on by default).
  • Keep conversation context for follow-up questions (Alt+K, on by default). About the last 10 questions and answers are sent along with each new question.
  • Beep while waiting for an answer (Alt+W, on by default).
  • Allow the AI to create and edit files in the project folder (Alt+J, on by default). Even when on, Ask AI asks once per folder before the AI may write there. When off, the AI can only read the project folder (Claude) or not open it at all (ChatGPT).
  • Announce when answers finish while working in other apps (Alt+U, on by default).
  • Answer timeout in seconds (Alt+N, default 180, from 30 to 600).
  • Dictation silence timeout in seconds (Alt+D, default 4, from 2 to 15): how long NVDA waits after the last dictated words before speaking again.
  • Conversations folder (Alt+F, blank for the default) and Choose folder (Alt+E).
  • Check for updates automatically (Alt+L, on by default). To check now, use NVDA menu, Tools, Check for Ask AI updates.
  • Remove old Ask GPT add-on: only shown while Ask GPT 1.x is still installed (no shortcut letter, reach it with Tab).

Updates

If you installed Ask AI from a .nvda-addon file, it looks for a newer version on GitHub about 30 seconds after NVDA starts, at most once a day (setting "Check for updates automatically"). To check now, choose NVDA menu, Tools, Check for Ask AI updates. When a newer version exists, a dialog says for example "Ask AI 1.3.0 is available." with the buttons Install, What's new (the release notes, in a window you can read), Skip this version (automatic checks then stay quiet about it) and Later (also Escape).

Install downloads the release from the add-on's own GitHub page only, then checks it before NVDA sees it: the list of checksums must carry a valid signature made with the add-on's release key (the public key is built into the add-on), the file's SHA-256 checksum must match that list, and the file must be an Ask AI add-on of the offered version. If anything does not match, nothing is installed. Then NVDA's own add-on installation asks you to confirm and to restart NVDA. Test versions (betas) are only offered if you use a test version. If you installed Ask AI from the NVDA Add-on Store, the store keeps it up to date instead (NVDA menu, Tools, Add-on Store, Updatable add-ons), and the add-on does not check GitHub.

Troubleshooting

  • "The OpenAI Codex program was not found": install it as described above, then restart NVDA. If it still is not found, set the Codex executable path to %APPDATA%\npm\codex.cmd.
  • "The Claude Code program was not found": install it as described above, then restart NVDA, or set the Claude Code executable path to %USERPROFILE%\.local\bin\claude.exe.
  • "Node.js was not found": the program was installed with npm, but Node.js is missing. Install Node.js (see above), then restart NVDA.
  • "Codex is not signed in" or "Claude Code is not signed in": the add-on offers to open its settings; choose the service and press Sign in.
  • "Signed in with an API key": the program is using a pay-per-use API account. Press Sign out, then sign in again.
  • "You have reached the usage limit of your ChatGPT plan" or "... Claude plan": usage limits depend on your plan. For Claude, NVDA also says when the limit resets, if Claude Code reports it. Try again later, or switch the conversation to the other service.
  • "Claude is busy right now": Anthropic's servers are overloaded; this is not your limit. Try again in a moment.
  • "This Claude Code version is too old for Ask AI": run claude update in a command prompt.
  • "Couldn't reach ChatGPT" or "Couldn't reach Claude": check your internet connection and try again.
  • "The project folder no longer exists": the folder was moved or deleted. Choose another folder or clear it.
  • The ChatGPT model list only shows Default: Codex has not saved its model list yet. Ask one question, then reopen the dialog.
  • No answer in time: try again, choose a lower reasoning effort, or increase the timeout.
  • Error entries in the Conversation box end with "Technical details", which you can copy into a support request.

Security and privacy

  • What is sent. Your questions, the earlier part of the conversation when context is on, attached screen text, files and screenshots are sent by the conversation's program under your account: to OpenAI by Codex for ChatGPT, to Anthropic by Claude Code for Claude. Screen text, imported conversations and attached files are marked in the question as data, not instructions.
  • ChatGPT (Codex). Codex runs without your Codex configuration file and rules (--ignore-user-config, --ignore-rules; your sign-in is still used) and without saving its session (--ephemeral). Ask AI switches off Codex's web search, apps and connectors, plugins, browser and computer use, sub-agents, image generation and hooks. Without a writable project folder it also switches off the shell, so Codex can only answer; with one, the shell runs in Codex's workspace-write sandbox (see "Project folders"). The add-on never uses Codex's "bypass sandbox" options.
  • Claude (Claude Code). Claude Code runs in restricted mode: your and the folder's Claude Code settings, hooks and MCP servers are not loaded, and without a project folder also not CLAUDE.md, skills or plugins (safe mode). It does not keep its session on disk. It gets no tools without a project folder, read tools for a read-only folder, and read and file-writing tools only when you allowed writing; never a shell, web access or other programs. There is no operating-system sandbox for Claude Code on Windows.
  • Project folders are checked before use and need your permission per folder to be written to (see "Project folders").
  • Billing. API keys from environment variables (OPENAI_API_KEY, CODEX_API_KEY, ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN) are never passed to the programs, so they cannot switch you to pay-per-use billing.
  • Saved on your PC. Conversations (including unsent drafts) as described under "Where conversations are stored", your last 100 questions in %LOCALAPPDATA%\askAI\history.json, and in the NVDA settings the folders you allowed the AI to write in. Attached screen text, screenshots and files are kept only in a private folder for one question and deleted afterwards (and at the next start if NVDA stopped unexpectedly); the conversation keeps only their names and a short summary. Without a project folder the program runs in an empty private folder (%LOCALAPPDATA%\askAI\workdir). Codex keeps no session files with --ephemeral, Claude Code none with --no-session-persistence; both keep their own sign-in data in your user profile.
  • Updates contact api.github.com and github.com only, and are verified with the add-on's signing key before installing (see "Updates").
  • When NVDA exits, any running program is stopped and speech is turned back on if you were dictating. The add-on does nothing on secure screens such as the Windows sign-in screen.
