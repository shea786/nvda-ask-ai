Ask GPT NVDA add-on

Ask ChatGPT a question from anywhere in Windows, by typing or by voice, and hear the answer read by NVDA. The add-on uses the official OpenAI Codex command line program, signed in with your ChatGPT account. Usage counts toward your ChatGPT plan (Plus, Pro, Team or Business). No API key is needed and there is no pay-per-use billing.

One-time setup

  1. Install Node.js (the LTS version) from nodejs.org. Accept the defaults in the installer.
  2. Open a command prompt: press Windows+R, type cmd and press Enter.
  3. Type npm install -g @openai/codex and press Enter. Wait until the prompt returns, then type exit and press Enter. Alternatively, download the Windows codex executable from github.com/openai/codex/releases and set its path in the add-on settings.
  4. Install this add-on (open the askGPT-1.0.0.nvda-addon file) and restart NVDA when asked.
  5. Open the NVDA menu (NVDA+N), choose Preferences, then Settings, and select the Ask GPT category.
  6. Press Sign in with ChatGPT. Your web browser opens the ChatGPT sign-in page. Sign in as usual. When the browser says you are signed in, return to NVDA. NVDA announces "Signed in with ChatGPT", or you can press Check status.
  7. Press OK to close the settings.

If the browser does not open, open a command prompt and run codex login yourself, then press Check status.

Asking a question

  1. Press NVDA+Alt+G from anywhere, or choose NVDA menu, Tools, Ask GPT. The Ask GPT dialog opens with the cursor in the Question box.
  2. Type your question and press Enter. Use Shift+Enter if you want a new line inside the question.
  3. NVDA says "Asking GPT" and plays a soft beep every two seconds while waiting. Answers usually take 5 to 30 seconds.
  4. When the answer arrives, NVDA reads it. It is also added to the Conversation box.
  5. Type a follow-up question and press Enter. GPT remembers the earlier questions of this conversation.

While waiting, press Escape (or the Cancel button, Alt+C) to cancel the question. When nothing is pending, Escape closes the dialog. The conversation is kept when you close the dialog, until you choose New conversation or restart NVDA.

Asking by voice

Press Alt+D (Dictate). NVDA says "Voice typing. Speak your question, then press Enter to send." After the message, Windows voice typing opens. Speak your question; the words are typed into the Question box. Then press Enter to send. This uses the voice typing built into Windows 10 and 11 (the same as pressing Windows+H). It needs an internet connection and "Online speech recognition" turned on in Windows Settings, Privacy, Speech. Headphones help so the microphone does not hear NVDA.

Reviewing answers

  • Press Alt+V to move to the Conversation box, then use the arrow keys to read the conversation line by line. Moving there places you at the start of the newest answer.
  • Copy last answer (Alt+O) copies the latest answer to the clipboard.
  • New conversation (Alt+N) clears the conversation so GPT forgets earlier questions.
  • Press NVDA+Alt+Shift+G from anywhere to hear the last answer again, even after closing the dialog. Press it twice quickly to open the answer in a window you can read with the arrow keys.

Both keyboard commands can be changed in NVDA menu, Preferences, Input gestures, category Ask GPT.

Settings

NVDA menu, Preferences, Settings, Ask GPT:

  • Status: shows Signed in with ChatGPT, Not signed in, or Codex CLI not found.
  • Sign in with ChatGPT, Check status, Sign out.
  • Codex executable path: leave blank to find Codex automatically. Use Browse to choose codex.exe or codex.cmd if it is installed somewhere unusual.
  • Model: leave blank to use the default model for your ChatGPT plan, or type a model name such as gpt-5.
  • Reasoning effort: Low is fastest and fine for most questions. Medium and High think longer.
  • Instructions for GPT: tells GPT how to answer. The default asks for short plain-text answers suited to a screen reader.
  • Speak answers automatically (on by default).
  • Keep conversation context for follow-up questions (on by default). About the last 10 questions and answers are sent along with each new question.
  • Answer timeout in seconds (default 180, from 30 to 600).

Troubleshooting

  • "The OpenAI Codex program was not found": install it as described above, then restart NVDA. If it still is not found, set the Codex executable path. For an npm install it is usually C:\Users\your name\AppData\Roaming\npm\codex.cmd.
  • "Codex is not signed in": the add-on offers to open its settings; press Sign in with ChatGPT.
  • "Signed in with an API key": Codex is using an API key, which is billed per use. Press Sign out, then Sign in with ChatGPT.
  • "You have reached the usage limit of your ChatGPT plan": Codex usage limits depend on your plan. Try again later.
  • No answer in time: try again, choose a lower reasoning effort, or increase the timeout.

Privacy

Your questions, and the earlier part of the conversation when context is on, are sent to OpenAI by the Codex program under your ChatGPT account. Codex runs in a read-only sandbox in an empty folder inside your NVDA settings folder (askGPT-workdir) and is told not to run commands or touch files. Codex may keep its own session logs in the .codex folder in your user profile. The add-on itself does not store questions or answers on disk. The add-on does nothing on secure screens such as the Windows sign-in screen.
