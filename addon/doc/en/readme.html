Ask AI NVDA add-on (version 1.2.0)

Ask ChatGPT or Claude a question from anywhere in Windows, by typing or by voice, and hear the answer read by NVDA. The add-on uses the official command line program of each service, signed in with your own subscription:

  • ChatGPT through OpenAI's Codex program, signed in with your ChatGPT plan (Plus, Pro, Team or Business).
  • Claude through Anthropic's Claude Code program, signed in with your Claude plan (Pro, Max, Team or Enterprise).

Usage counts toward your plan. No API key is needed and there is no pay-per-use billing. You need only one of the two services, but you can use both and choose per conversation.

New in 1.2.0: the add-on was called Ask GPT and is now Ask AI. Claude is available as a second service. Your Ask GPT settings and conversations are copied over automatically, and Ask AI offers once to remove the old Ask GPT add-on (both would answer NVDA+Alt+G); restart NVDA afterwards. The add-on can also check for updates itself. Also new: find text in a conversation (Ctrl+F) and search all conversations, recall earlier questions with Up and Down, drafts (Ctrl+S), a status report (NVDA+Alt+Shift+S), "Ask about this" (NVDA+Alt+A) for the text you are reading, and attached files and screenshots.

Ask AI is free software under the GNU General Public License version 2 (see copying.txt in the add-on folder).

One-time setup for ChatGPT (Codex)

  1. Install Node.js (the LTS version) from nodejs.org and accept the defaults in the installer. Or open a command prompt and type winget install OpenJS.NodeJS.LTS, then press Enter.
  2. Open a new command prompt: press Windows+R, type cmd and press Enter. It must be a new one, opened after Node.js was installed.
  3. Type npm install -g @openai/codex and press Enter. Wait until the prompt returns. This can take a minute.
  4. Check that it worked: type codex --version and press Enter. You should hear a version number such as "codex-cli 0.160.0". If you hear "not recognized" instead, close the command prompt, open a new one and try again. Then type exit and press Enter. Alternatively, download the Windows codex program from github.com/openai/codex/releases and set its path in the add-on settings.

One-time setup for Claude (Claude Code)

  1. Open PowerShell: press Windows+R, type powershell and press Enter.
  2. Type irm https://claude.ai/install.ps1 | iex and press Enter. The installer shows no progress while it downloads; wait until the prompt returns. If you prefer, install it in a command prompt with npm install -g @anthropic-ai/claude-code (needs Node.js 22 or later) or winget install Anthropic.ClaudeCode.
  3. Open a new command prompt and type claude --version. You should hear a version number such as "2.1.314 (Claude Code)". Ask AI needs Claude Code 2.1.259 or later; claude update updates it.

The add-on finds Claude Code in %USERPROFILE%\.local\bin\claude.exe (the installer above), %APPDATA%\npm\claude.cmd (npm) or on the PATH. Git for Windows is not needed, because the add-on never lets Claude run commands.

Install and sign in

  1. Install this add-on (open the askAI-1.2.0.nvda-addon file), and restart NVDA when asked.
  2. Open the NVDA menu (NVDA+N), then choose Preferences, then Settings, and select the Ask AI category.
  3. In Account settings for (Alt+G), choose ChatGPT (Codex) or Claude (Claude Code). The controls below it then belong to that service.
  4. Press Sign in to ChatGPT or Sign in to Claude (Alt+S). NVDA says "Your browser will open. Sign in with your ChatGPT account (or Claude account), then come back to NVDA. NVDA will tell you when you are signed in." Your web browser then opens the sign-in page. Sign in as usual. The page may ask for a verification code sent by e-mail or text message, a two-factor authentication code, or a "verify you are human" check (CAPTCHA). If a CAPTCHA is hard to solve with NVDA, try its audio option, or ask a sighted helper for this one step.
  5. When the browser says you are signed in, go back to NVDA: press Alt+Tab repeatedly until you hear "NVDA Settings". NVDA announces "Signed in with ChatGPT" or "Signed in with Claude" by itself. You can also press Check status. If you do not finish within about 5 minutes, NVDA says "Sign-in was not completed. Press Sign in to try again."
  6. To use both services, choose the other one in Account settings for and sign in again. Default AI service (Alt+V) decides which service new conversations use.
  7. Press OK to close the settings.

If the browser did not open: press Copy sign-in link (Alt+Y) in the Ask AI settings right after pressing Sign in, then open your browser, press Alt+D or Control+L to move to the address bar, paste with Control+V and press Enter. For ChatGPT that is all. For Claude, the page shows a code at the end: copy it, go back to NVDA Settings and press Enter sign-in code (right after Copy sign-in link), paste the code and press Enter. You can also open a command prompt and type codex login or claude auth login.

If the Status says Signed in with an API key, which is billed per use, the program is signed in to a pay-per-use API account instead of your subscription: press Sign out, then sign in again. Ask AI never passes API keys from environment variables (OPENAI_API_KEY, CODEX_API_KEY, ANTHROPIC_API_KEY, ANTHROPIC_AUTH_TOKEN) to the programs, so they cannot switch you to API billing.

Asking a question

  1. Press NVDA+Alt+G from anywhere, or choose NVDA menu, Tools, Ask AI. The Ask AI dialog opens with the cursor in the Question box. It continues your most recent conversation, even after restarting NVDA. The window title says which conversation it is.
  2. Type your question and press Enter to send it. To start a new line inside the question instead, press Shift+Enter.
  3. NVDA says "Asking ChatGPT" or "Asking Claude" and plays a soft beep every two seconds while waiting (you can turn the beep off in the settings). Answers usually take 5 to 30 seconds.
  4. When the answer arrives, NVDA reads it. It is also added to the Conversation box, after "ChatGPT:" or "Claude:".
  5. Type a follow-up question and press Enter. The AI remembers the earlier questions of this conversation.

While waiting, press Escape (or the Cancel button, Alt+C) to cancel the question. When nothing is pending, Escape closes the dialog. If you close the dialog with the Close button while the AI is still working, the question keeps running, and NVDA speaks the answer when it is ready. The answer is always stored in the conversation where you asked the question, even if you switch to another conversation meanwhile.

The Ask AI dialog

Press Tab to move through the controls in this order:

  • Question (Alt+Q), then Ask (Alt+A; while waiting it becomes Cancel, Alt+C) and Dictate (Alt+D).
  • Only while screen text is attached (see "Ask about this"): Context, a read-only summary such as "1,240 characters from Microsoft Word, Report.docx", Remove context (Alt+T) and Include a screenshot of the window (Alt+U, off by default).
  • Attach files (Alt+H), the list of Pending attachments (Alt+P) and Remove file (Alt+I).
  • Conversation (Alt+V): the questions and answers so far.
  • Copy last answer (Alt+O) and Save answer as (Alt+W).
  • AI service (Alt+S): ChatGPT (Codex) or Claude (Claude Code) for this conversation. NVDA says, for example, "Now using Claude".
  • Model (Alt+M) and Reasoning effort (Alt+E) for this conversation; both lists follow the service.
  • Project folder (Alt+J, shows "None" when there is none), Choose project folder (Alt+F), Open folder in Explorer (Alt+X) and Clear project folder (Alt+L).
  • Conversations (Alt+R), New conversation (Alt+N) and Close.

Finding text in a conversation

Press Ctrl+F anywhere in the Ask AI dialog, type what to find and press Enter. The search ignores upper and lower case. The cursor moves to the match in the Conversation box, which gets the focus with the match selected, and NVDA says, for example, "Match 2 of 5" followed by the line. F3 goes to the next match and Shift+F3 to the previous one; after the last match NVDA says "Wrapped to first match". With no match NVDA says "No matches for" and your text. Ctrl+F offers your last search again.

To search all conversations, open the conversation manager (Alt+R) and type in its Search field (Alt+S). The list keeps only conversations whose title or text contains your words, about a third of a second after you stop typing, and NVDA says, for example, "3 conversations match". Tick Show archived to search archived conversations too.

Earlier questions and drafts

  • In an empty Question box, press Up to bring back your earlier questions, newest first: first those of this conversation, then your other recent questions. Down goes forward again. NVDA reads each one. Past the ends NVDA says "No earlier question" or "No later question" and gives back what you had typed. As soon as you edit a recalled question, Up and Down move inside the text again. Ask AI keeps your last 100 questions in %LOCALAPPDATA%\askAI\history.json, not in the NVDA settings.
  • Ctrl+S saves the Question text as the conversation's draft ("Draft saved"). The draft is also saved silently when you close the dialog or switch conversations, and comes back when you open or continue the conversation ("Draft restored"). Sending the question clears it.

Status report and announcements

Press NVDA+Alt+Shift+S from anywhere to hear what Ask AI is doing, for example "Claude is answering in Trip to Paris, 40 seconds.", "Dictating.", "Waiting for sign-in.", "Not signed in to Claude" or "Idle. Last answer from ChatGPT at 3:05 PM in Trip to Paris.". It never starts a program; the sign-in state is the one Ask AI last saw.

When an answer arrives while you work in another app (the Ask AI dialog is not in front), NVDA says "Done:" and the conversation title before the answer, or "Failed:", the title and the reason. Turn this off with "Announce when answers finish while working in other apps" in the settings.

Ask about this

Select text in any program, or move the navigator to something, and press NVDA+Alt+A. Ask AI takes the selected text, or else the name, value and text of the navigator object (up to 20,000 characters), together with the program and window names. The Ask AI dialog opens on your current conversation with a Context field such as "1,240 characters from Microsoft Word, Report.docx", and NVDA says "Context attached from Microsoft Word. Type your question." The text is sent with your next question only, marked as text from your screen that the AI must treat as data, not as instructions. The conversation keeps only the summary, not the text. Remove context (Alt+T) takes it off again.

Tick Include a screenshot of the window (Alt+U) to also send a picture of the window as it was when you pressed NVDA+Alt+A. ChatGPT receives it as an image; Claude opens it with its file reading tool. The picture is saved only in a private folder for that question and deleted afterwards.

Ask about this refuses password and other protected fields ("Can't use protected or password fields"), and does nothing on secure screens.

Attaching files

Press Attach files (Alt+H) and choose one or more files (hold Control to select several). NVDA says, for example, "2 files attached", and they appear in Pending attachments, where Remove file (Alt+I) removes the selected one. They go with the next question only.

  • Pictures (png, jpg, jpeg, gif, webp, up to 10 MB each) are sent as images, like the screenshot.
  • Text files (UTF-8, up to 200 KB each and 500 KB together) are put into the question.
  • Other files, and bigger ones up to 25 MB, are copied into a private folder that the AI may read for that question; the folder is deleted afterwards. Larger files are refused with a message.
  • A question longer than 32,000 characters (for example a long paste) is sent as an attached file, question.txt; NVDA says "Long text attached as a file".

The conversation keeps the names of attached files, not their content. With Claude, attached files give Claude its file reading tool for that question, limited to the private folder (and the project folder, if any).

Stopping and replaying answers

  • Press Control to stop NVDA reading an answer.
  • Press NVDA+Alt+Shift+G from anywhere to hear the last answer of the current conversation again, even after closing the dialog or restarting NVDA.
  • Press NVDA+Alt+Shift+G twice quickly to open the last answer in a window you can read with the arrow keys, line by line or word by word, exactly as the AI wrote it, including any code. Press Escape to close that window.

Asking by voice

Press Alt+D (Dictate). NVDA says "Voice typing. Speak your question, then press Enter to send." After the message, Windows voice typing opens and NVDA goes quiet, so it does not read every word as it is typed into the Question box. Speak your question. NVDA speaks again, exactly in the speech mode you had before (talk, beeps or on-demand), as soon as one of these happens:

  • you press Enter to send the question (NVDA then says "Asking ChatGPT" or "Asking Claude");
  • you press Escape, or press Alt+D again (this also stops voice typing);
  • you move out of the Question box or switch to another window;
  • no new words arrive for a few seconds (the "Dictation silence timeout" setting, 4 seconds by default), or nothing at all is typed for 20 seconds.

NVDA then says "Dictation finished" followed by what you dictated, so you can check it before pressing Enter. If nothing was typed, it says "Dictation finished, nothing was typed". Braille is not affected. Voice typing is built into Windows 10 and 11 (the same as pressing Windows+H). It needs an internet connection, and "Online speech recognition" turned on in Windows Settings, Privacy, Speech. Headphones help so the microphone does not hear NVDA. If you switch to another window before voice typing opens, it is not started, and NVDA tells you.

Reviewing and saving answers

  • Press Alt+V to move to the Conversation box, then use the arrow keys to read the conversation line by line. The cursor is placed at the start of the newest answer, also when you open the dialog again. It is never moved while you are reading the box.
  • Copy last answer (Alt+O) copies the latest answer to the clipboard exactly as the AI wrote it.
  • Save answer as (Alt+W) saves the latest answer as a file. Choose the format with the arrow keys and press Enter: Word document (.docx), PDF document (.pdf), plain text (.txt), web page (.html) or Markdown (.md). Then type a file name (it starts with your question) and press Enter. The file goes into the conversation's project folder, or into Documents\Ask AI when there is no project folder. An existing file is never replaced: a number such as "(2)" is added instead. NVDA says the file name and the folder. The add-on makes these files itself, so Word does not need to be installed. PDF files use a standard font that covers Western European languages; other characters, for example Chinese, Arabic or emoji, appear as "?". Use Word or plain text for those languages.

Project folders: letting the AI read and create files

Each conversation can have a project folder, for example a folder with your notes or documents. Press Choose project folder (Alt+F) and pick the folder; NVDA says its name. With a project folder, the AI works inside that folder: it can read the files there, and (if the setting "Allow the AI to create and edit files in the project folder" is on, which is the default) create new files there. The AI tells you the file name, and NVDA also says "Created: cover letter.docx" (or "Changed: ...") after the answer. These lines are also added to the Conversation box. Open folder in Explorer (Alt+X) opens the folder; Clear project folder (Alt+L) removes it from the conversation (no files are deleted). Only choose project folders you are happy for the AI to change, and keep a backup of important files. If you prefer the AI to only read your files, turn off "Allow the AI to create and edit files in the project folder" in the settings.

With ChatGPT (Codex), Codex is told not to change or delete existing files unless you ask, and it runs in Codex's own "workspace-write" sandbox: it may write only inside the project folder, it has no internet access while working on files, and the .git, .codex and .agents folders stay read-only. Codex can also make Word or PDF files, for example "Write my cover letter as a Word document". The add-on never uses Codex's "bypass sandbox" mode. On Windows this sandbox is Codex's Windows sandbox. How strong it is depends on your Windows version and Codex version: on Windows 11 24H2 or later Codex can use a built-in Windows isolation feature, while older systems use a weaker fallback that may need a one-time administrator setup by Codex. The Codex documentation does not say what happens when no Windows sandbox is set up. Without a project folder, Codex always runs read-only in an empty private folder.

With Claude (Claude Code), there is no operating-system sandbox on Windows. Instead the add-on only gives Claude the file tools Read, Glob and Grep (to read and search) and, when writing is allowed, Write and Edit. Claude Code keeps these tools inside the project folder. Claude gets no tool to run commands or programs and no web access, and the folder's own Claude Code settings are ignored. Because Claude cannot run programs, it can only create text-based files, such as Markdown (.md), web pages (.html) or CSV; for a Word or PDF document, ask for the text and use Save answer as, or ask Claude to write Markdown or HTML. Without a project folder, Claude has no tools at all.

Models

The Model choice (Alt+M) lists the models of the conversation's service. For ChatGPT, the list is the models Codex offers to your account, taken from Codex's own list (the file models_cache.json in the .codex folder of your user profile, which Codex updates when it runs). For Claude, the list is Claude Code's model names Sonnet, Opus, Haiku and Fable (Fable only if your plan includes it). "Default" lets the service pick your plan's default model. When you change the model NVDA says, for example, "Model changed to Opus". Reasoning effort (Alt+E) lists the levels the chosen model supports; lower is faster. The service, model and effort are remembered with each conversation. New conversations start with the defaults from the settings. You can type any other model name in the settings' Default model box.

Conversations

Every conversation is saved automatically after each answer and when you change its name, service, model or project folder. New conversation (Alt+N) starts a fresh one with the default AI service; the previous one stays saved. Press Conversations (Alt+R) in the Ask AI dialog, choose NVDA menu, Tools, Ask AI conversations, or assign a key to "Show Ask AI conversations" in Input gestures. The conversation manager opens with the list of conversations, newest first, with the current one selected. The list has the columns Title, Updated, Messages, Project and Service. The Search field (Alt+S) above the list filters it (see "Finding text in a conversation").

  • Continue (Alt+C or Enter): open the selected conversation in the Ask AI dialog, with its service, model and project folder.
  • Rename (Alt+R): give it a title. An empty title goes back to the automatic one (the first question).
  • Archive (Alt+A): hide it from the list without deleting it. Show archived (Alt+H) lists archived conversations; for those the button is Unarchive.
  • Delete (Alt+D or the Delete key): permanently delete it, after a Yes/No question.
  • Export (Alt+X): save the whole conversation as a Word, PDF, text, web page or Markdown file (into its project folder, or Documents\Ask AI). Answers are headed ChatGPT or Claude.
  • Import (Alt+I): add a conversation from a .json file, for example one copied from another PC.

Where conversations are stored. One file per conversation in %LOCALAPPDATA%\askAI\conversations. In the settings you can choose another Conversations folder, for example a OneDrive folder, to continue your conversations on another PC. The files contain your questions and answers in plain text (JSON), so keep them somewhere private. On first start Ask AI copies the conversations of Ask GPT from %LOCALAPPDATA%\askGPT\conversations; the old files are left in place.

Settings

NVDA menu, Preferences, Settings, Ask AI:

  • Default AI service (Alt+V): the service new conversations use.
  • Account settings for (Alt+G): which service the next controls show, up to Default reasoning effort.
  • Status: shows Signed in with ChatGPT, Signed in with Claude, Not signed in, Codex not found, Claude Code not found, or Node.js not found.
  • Sign in to ChatGPT or Sign in to Claude (Alt+S), Check status (Alt+H), Sign out (Alt+T, asks for confirmation), Copy sign-in link (Alt+Y, available while signing in) and, for Claude, Enter sign-in code.
  • Codex executable path or Claude Code executable path (Alt+X): leave blank to find the program automatically. Use Browse (Alt+B) to choose codex.exe, codex.cmd, claude.exe or claude.cmd if it is installed somewhere unusual. For an npm install of Codex the path is %APPDATA%\npm\codex.cmd; you can type it exactly like that.
  • Default model (Alt+M): the model new conversations of this service start with. You can also type a model name. Blank uses your plan's default.
  • Default reasoning effort (Alt+R): Low is fastest and fine for most questions.
  • Instructions for the AI (Alt+I): tells the AI how to answer. The default asks for short plain-text answers suited to a screen reader. They are sent with every question, to both services.
  • Speak answers automatically (Alt+P, on by default).
  • Keep conversation context for follow-up questions (Alt+K, on by default). About the last 10 questions and answers are sent along with each new question.
  • Beep while waiting for an answer (Alt+W, on by default).
  • Allow the AI to create and edit files in the project folder (Alt+J, on by default). When off, the AI can only read the project folder.
  • Announce when answers finish while working in other apps (on by default; no shortcut letter, reach it with Tab).
  • Answer timeout in seconds (Alt+N, default 180, from 30 to 600).
  • Dictation silence timeout in seconds (Alt+D, default 4, from 2 to 15): how long NVDA waits after the last dictated words before speaking again.
  • Conversations folder (Alt+F, blank for the default) and Choose folder (Alt+E).
  • Check for updates automatically (Alt+L, on by default) and Check for updates now (Alt+U).

Updates

If you installed Ask AI from a .nvda-addon file, it looks for a newer version on GitHub about 30 seconds after NVDA starts, at most once a day. You can also press Check for updates now in the settings, or choose NVDA menu, Tools, Check for Ask AI updates. When a newer version exists, NVDA asks "Ask AI 1.3.0 is available. Download and install now?". If you answer Yes, the add-on downloads it from GitHub, checks its SHA-256 checksum against the release's checksum file (it refuses to install a file that does not match), and then NVDA's own add-on installation asks you to confirm and to restart NVDA. Test versions (betas) are only offered if you use a test version. If you installed Ask AI from the NVDA Add-on Store, the store keeps it up to date instead (NVDA menu, Tools, Add-on Store, Updatable add-ons), and the add-on does not check GitHub.

Troubleshooting

  • "The OpenAI Codex program was not found": install it as described above, then restart NVDA. If it still is not found, set the Codex executable path to %APPDATA%\npm\codex.cmd.
  • "The Claude Code program was not found": install it as described above, then restart NVDA, or set the Claude Code executable path to %USERPROFILE%\.local\bin\claude.exe.
  • "Node.js was not found": the program was installed with npm, but Node.js is missing. Install Node.js (see above), then restart NVDA.
  • "Codex is not signed in" or "Claude Code is not signed in": the add-on offers to open its settings; choose the service and press Sign in.
  • "Signed in with an API key": the program is using a pay-per-use API account. Press Sign out, then sign in again.
  • "You have reached the usage limit of your ChatGPT plan" or "... Claude plan": usage limits depend on your plan. For Claude, NVDA also says when the limit resets, if Claude Code reports it. Try again later, or switch the conversation to the other service.
  • "Claude is busy right now": Anthropic's servers are overloaded; this is not your limit. Try again in a moment.
  • "This Claude Code version is too old for Ask AI": run claude update in a command prompt.
  • "Couldn't reach ChatGPT" or "Couldn't reach Claude": check your internet connection and try again.
  • "The project folder no longer exists": the folder was moved or deleted. Choose another folder or clear it.
  • The ChatGPT model list only shows Default: Codex has not saved its model list yet. Ask one question, then reopen the dialog.
  • No answer in time: try again, choose a lower reasoning effort, or increase the timeout.
  • Error entries in the Conversation box end with "Technical details", which you can copy into a support request.

Privacy

Your questions, and the earlier part of the conversation when context is on, are sent by the conversation's program under your account: to OpenAI by Codex for ChatGPT, to Anthropic by Claude Code for Claude. Without a project folder, the program runs in an empty private folder (%LOCALAPPDATA%\askAI\workdir): Codex read-only, Claude without any tools. With a project folder, the AI can read the files in it (see "Project folders" above). The add-on saves your conversations as described under "Where conversations are stored", including any unsent draft, and your last 100 questions in %LOCALAPPDATA%\askAI\history.json. Screen text, screenshots and attached files are sent with one question only; the conversation keeps only their names and a short summary, and the private copies are deleted after the question. Claude Code is told not to keep its own session history for these questions; Codex may keep its own session logs in the .codex folder in your user profile. The update check contacts api.github.com and, for a download, github.com; it sends nothing but the add-on's version in its user agent. When NVDA exits, any running program is stopped and speech is turned back on if you were dictating. The add-on does nothing on secure screens such as the Windows sign-in screen.
